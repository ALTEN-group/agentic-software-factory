# 🧰 Outillage

Les outils déconnectés dispersent le contexte des agents. Exigences, notes de réunion, code, journaux CI et releases doivent rester liés.

> Utilisez **une plateforme Git**, comme GitHub ou GitLab, pour le cycle de livraison.

## Pourquoi une plateforme unique est essentielle pour l’IA

1. **Traçabilité** : suivre la citation client dans le ticket, le plan, le code, les contrôles et la release.
2. **Liens natifs** : relier tickets, branches, demandes de fusion, prévisualisations et tags sans synchronisation sur mesure.
3. **Accès cohérents** : partager les permissions et journaux d’audit.
4. **Contexte plus accessible** : utiliser les API de la plateforme plutôt que des intégrations dispersées.

## La pile Git unifiée

Gardez tickets, branches, demandes de fusion, pipelines, environnements et releases au même endroit.

## Éliminer l’éparpillement des outils

Avant d’ajouter un outil externe, consignez pourquoi la plateforme ne répond pas au besoin et comment les agents garderont accès à son contexte.
